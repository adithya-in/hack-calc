A modern calculator.

Hand-assembled with care. Three modes cycle every 2 seconds, recreating the classic calculator experience with a modern twist.

On the outside

On the inside

FEATURES

Built with intent.

Custom ST7789 Offsets

Patched rotation for 76×284 GRAM window. Every pixel lands exactly where it should.

Active-Low Backlight

PWM dimming with inverted duty cycle. Brightness tuned per mode for optimal readability.

Hand-Tuned Palette

Background #152228, text #bccfc4, subtle grid. Nails that authentic LCD glow.

2-Second Cycle

Clean state machine. Casio → Porsche → Cheat sheet, repeat.

Raw-GRAM Diagnostics

Stripe test bypasses offsets for easy hardware debugging.

Fully Open Source

MIT licensed. Wiring, patch, image pipeline, and docs all included.
